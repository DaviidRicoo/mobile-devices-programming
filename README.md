---

## 📌 Descripción del Repositorio

Este repositorio reúne las prácticas, laboratorios y proyectos desarrollados en la asignatura **Mobile Devices Programming**. El objetivo es aprender el desarrollo de aplicaciones nativas para Android utilizando **Kotlin**, aplicando patrones de arquitectura modernos (MVVM), gestión del ciclo de vida de componentes, persistencia de datos y consumo de servicios web.

---

## 🛠️ Herramientas y Stack Tecnológico

* **Lenguaje:** Kotlin
* **IDE:** Android Studio
* **Build Tool:** Gradle (Kotlin DSL / Groovy)
* **Arquitectura & Librerías:** MVVM, Jetpack Compose / XML Layouts, Room DB, Retrofit, Coroutines, LiveData
